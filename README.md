# Bash Script Practice

## Описание

Проект выполнен в рамках контрольной точки по Bash.

Скрипт `project-helper.sh` автоматически:

- получает название проекта;
- создаёт папку проекта;
- создаёт файлы;
- записывает информацию в файлы;
- проверяет существование проекта;
- подсчитывает количество файлов;
- создаёт отчёт о выполнении.

## Используемые команды

В работе используются:

- `echo`
- `read`
- `chmod`
- `mkdir`
- `touch`
- `cat`
- `find`
- `wc`
- `date`
- `ls`

Также используются:

- переменные;
- условие `if`;
- цикл `for`;
- функция;
- перенаправление вывода `>` и `>>`;
- аргумент командной строки `$1`.
